# Pandas Basics and Data Analysis Tasks


* **`pandasTask.py`**: The main Python script containing various data manipulation and analysis tasks.

## Prerequisites
To run this script, you will need Python installed on your system along with the following libraries:
* `pandas`


You can install the required libraries using pip:
```bash
pip install pandas
```

## Usage

Simply run the script from your terminal or command prompt:

```bash
python pandasTask.py
```

### Outputs
Upon execution, the script will:
1. Print the results of various Pandas operations to the console.
2. Generate and save four `.png` image files in the same directory representing the data visualizations from Task 8 and Task 9.
